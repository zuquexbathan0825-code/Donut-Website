# Donut Store Website

A modern, sleek website for the Donut SMP store featuring rank packages and free trial ranks.

## Features

- **Ranks Section**: Premium subscription tiers
  - Donut+ ($4.99/month)
  - Donut++ ($9.99/month)
  - Donut+++ ($14.99/month)

- **Free Ranks Section**: Trial rank packages
  - Donut+ (Claim Trial)
  - Donut++ (Claim Trial)
  - Donut+++ (Claim Trial)

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Deployment

This website is optimized for deployment on Cloudflare Pages.
